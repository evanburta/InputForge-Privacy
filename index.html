InputForge

Privacy Policy

Last updated: March 20, 2026 No data collected Android App
InputForge is a gamepad remapping application for Android. This policy explains what data the App stores, how it is used, and your rights. The short version: everything stays on your device.

01 Data Stored on Your Device

All App data is stored exclusively on your device. There are no user accounts, cloud sync, or remote databases.

  • Controller profiles Button remapping configs, analog stick, trigger, gyro settings, action layers, action sets, and macros — stored as JSON in Android DataStore.
  • App preferences Cheat sheet overlay settings (mode, opacity, panel visibility), first-launch flag, and UI preferences — stored in Android DataStore.
  • Entitlement data Whether the Pro upgrade has been purchased and gyro trial usage (session count, start date) — stored in Android DataStore.
  • ADB credentials Security keys used to authenticate with your device's wireless debugging interface. Generated on-device and never transmitted externally.
  • Shell helper metadata Technical data used to manage the App's background service — stored in SharedPreferences.
  • Service log A local debugging log capped at 50 KB, stored in the App's private file directory.

02 Data Not Collected

The App does not collect, store, or transmit any of the following:

  • Personal information
  • Device identifiers
  • Location data
  • Contacts or calendar
  • Photos or media
  • Browsing history
  • Analytics or telemetry
  • Crash reports
  • IMEI or serial number
  • Advertising ID

03 Network Communications

Steam Workshop API

The App may connect to the Steam Web API (Valve Corporation) to fetch controller configurations when explicitly requested by the user. No personal data is transmitted.

Local Shell Helper

The App communicates with its on-device shell helper over localhost TCP (port 38291). This is strictly device-internal — no data leaves your device through this channel.

✓ The App contains no analytics SDKs, advertising libraries, crash reporting services, or telemetry of any kind.

04 Permissions

Permission Purpose
Accessibility Service Intercepts gamepad button events for remapping, detects foreground app for automatic profile switching, and reads the wireless debugging pairing code during setup. Does not read personal content from other apps.
Internet Used solely to fetch Steam Workshop configs when you explicitly request an import.
Foreground Service Keeps the input remapping pipeline active while the App is in the background.
Post Notifications Shows a persistent notification while remapping is active, and displays the ADB pairing code during setup (Android 13+).
System Alert Window Displays the cheat sheet and radial menu overlays on top of other apps.
Query All Packages Lists installed apps so you can associate controller profiles with specific games.
Access Network State Checks Wi-Fi connectivity status during wireless debugging setup.

05 Accessibility Service Disclosure

The Accessibility Service is used for three specific purposes:

  • 1
    Intercept gamepad key events The core mechanism that enables button remapping when the shell helper is not active.
  • 2
    Detect foreground app changes Allows automatic profile switching when you open a different game.
  • 3
    Read the pairing code During one-time wireless debugging setup, reads the 6-digit pairing code from Android's Developer Settings to streamline pairing.
✓ The Accessibility Service does  not  read, collect, store, or transmit the content of other apps, text fields, passwords, messages, or any personal information.

06 Third-Party Services

No other third-party services, SDKs, or libraries that collect or transmit user data are included in the App.

07 In-App Purchases

The App offers a Pro upgrade through Google Play. Purchase transactions are handled entirely by Google Play and are subject to Google's Privacy Policy. The App only stores a local flag indicating whether the Pro upgrade has been purchased.

08 Children's Privacy

The App does not knowingly collect any personal information from children under 13. The App does not contain advertising, social features, or user accounts.

09 Data Deletion

All data is stored locally on your device. You can delete everything at any time:

  • → Android Settings → Apps → InputForge → Storage → Clear Data
  • → Uninstall the App

No data is retained on any external server.
